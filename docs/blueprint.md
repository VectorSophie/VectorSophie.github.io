# **App Name**: Neon Portfolio

## Core Features:

- Repository Display: Display up to 6 of the user's main GitHub repositories in a card format, fetched from https://github.com/VectorSophie.
- Blog Post Display: Display the most recent blog post from the user's Naver blog at https://blog.naver.com/paranormalian in a card format. Use a tool to periodically scrape blog post information and summarize blog content.
- Svelte Integration: Implement the entire application using Svelte.

## Style Guidelines:

- Background color: Dark gray (#222222) for a dark mode aesthetic.
- Primary color: Light purple (#94b1ff) as requested, for a neon pop against the dark background.
- Accent color: Electric blue (#7DF9FF) to highlight interactive elements and add to the neon aesthetic.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, techy feel.
- Body font: 'Inter' (sans-serif) to complement 'Space Grotesk' in longer text blocks.
- Use minimalist, glowing icons to represent different categories and actions. Keep icon set consistent in style.
- Card-based layout for repositories and blog posts, providing a clean and organized display.
- Subtle hover effects on cards to provide interactivity feedback and a polished feel.
